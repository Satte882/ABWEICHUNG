# ABWEICHUNG

Arbeitstitel für Buch 2 einer thematischen Psychothriller-Reihe.

## Status

**Konzept gesetzt. Storyentwicklung bewusst pausiert.**

Bevor Plot, Figuren, Kapitel oder Prosa entwickelt werden, wird aus `Satte882/Buch` systematisch extrahiert, welche Methoden, Qualitätsgates, Arbeitsabläufe und Produktionsbausteine für weitere Bücher wiederverwendbar sind. Diese wiederverwendbare Logik wird getrennt in `Satte882/Buch-Framework` aufgebaut.

`ABWEICHUNG` soll anschließend das erste Buch sein, das bewusst mit diesem Framework entwickelt wird.

## Reihengedanke

Die Bücher sind keine klassische Fortsetzungsreihe mit denselben Figuren. Gemeinsam ist die dramaturgische Denkmaschine:

> Ein gesellschaftlich nachvollziehbares Problem trifft auf eine zunächst vernünftige Lösung. Die Lösung funktioniert. Gerade ihr Erfolg verschiebt schrittweise eine Grenze, bis etwas normal oder legitim erscheint, das zu Beginn kaum akzeptabel gewesen wäre.

Die Gefahr entsteht damit nicht primär durch ein System, das versagt, sondern durch eines, das **funktioniert**.

## Buch 2 – thematischer Kern

**Thema:** KI + Entscheidungsmacht

**Konflikt:** Ergebnisqualität vs. legitime menschliche Entscheidungsmacht

**Zentrale Frage:**

> **Wie lange darf ein Mensch eine schlechtere Entscheidung treffen, wenn eine Maschine nachweislich die bessere kennt?**

Zweite Zuspitzung:

> **Wann wird menschliche Entscheidungsfreiheit unverantwortlich?**

## Dramaturgischer Grundmechanismus

Noch kein Plot, sondern die zentrale Bewegungslogik:

1. KI berät Menschen bei relevanten Entscheidungen.
2. Die KI erzielt nachweislich bessere Ergebnisse.
3. Menschliche Overrides führen in einzelnen Fällen zu vermeidbarem Schaden.
4. Abweichungen von der KI-Empfehlung müssen zunehmend begründet werden.
5. Die Hürden für einen Override steigen Schritt für Schritt.
6. Der Mensch bleibt formal in der Entscheidungsschleife, verliert aber faktisch Entscheidungsmacht.

Kernumkehr:

> **Nicht mehr die Maschine muss beweisen, dass sie recht hat. Der Mensch muss beweisen, warum er von ihr abweichen darf.**
