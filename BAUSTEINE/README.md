# BAUSTEINE – kanonische Storystruktur

Dieses Verzeichnis ist die kanonische Arbeitsstruktur für die Story-Architektur von **ABWEICHUNG**.

Die Ableitungsrichtung ist:

`Buchidee / Story Package → Baustein → Events → Szenen → Beats → Prosa`

Jeder Baustein besitzt einen eigenen Ordner `Bxx/` mit:

- `BAUSTEIN.md` – dramaturgische Funktion und Makroentscheidung,
- `EVENTS.md` – Ereignisse/Sequenzen dieses Bausteins,
- später `SZENEN/Sxxx/SZENE.md`,
- darin `BEATS.md`, `CHARACTER_STATES.md` und erst ganz unten `PROSA.md`.

## Kanonische Regel

Die verschachtelte Struktur unter `BAUSTEINE/` ist die fachliche Source of Truth für Bausteine, Events, Szenen, Beats und Prosa.

Die Root-Dateien `STORY_BLOCKS.md` und `EVENTS.md` bleiben vorerst als **abgeleitete Gesamt-/Checker-Sicht** erhalten. Sie dürfen nicht unabhängig von den Baustein-Dateien weiterentwickelt werden.
