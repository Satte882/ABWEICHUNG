# BAUSTEINE

Diese Ordner sind die kanonische Story-Hierarchie von ABWEICHUNG.

## Regel

`Baustein → Ereignisse → Szenen → Beats → Prosa`

- `BAUSTEIN.md` definiert die dramaturgische Funktion des Abschnitts.
- `EREIGNISSE/EREIGNISSE.md` definiert die kausale Ereigniskette des Bausteins.
- `SZENEN/` entsteht erst in G2, wenn aus den Ereignissen konkrete erzählte Szenen abgeleitet werden.
- Jede Szene erhält später `SZENE.md` und `BEATS.md`.
- `PROSA.md` entsteht erst nach G2/G3 und ist immer die unterste Ebene.
